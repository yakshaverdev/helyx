# 2026-11-07: the command hook (#883)

## Done

- `Helyx.Hook.Command`, a bundled hook plugin on `before_tool` and `after_tool` (ADR 0013 §8): config under `:command_hook`, the call as JSON on standard input in the Claude Code field names, exit 0 / 2 / other, the JSON answer shapes, and a bound of 262,144 bytes on each of standard output and standard error.
- The watchdog merges standard error into its port, so a small perl relay (`plugins/bundled/lib/helyx/hook/command/relay.pl`) runs the command with two pipes and writes frames. Core, the hands, and the watchdog are unchanged.
- Feature doc `docs/features/command-hook.md`; research note `docs/research/claude-code-hooks.md` (the field names, observed in the Claude Code 2.1.319 binary).
