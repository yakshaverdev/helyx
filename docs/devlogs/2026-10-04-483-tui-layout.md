# 2026-10-04: TUI layout (#483)

## Done

- `Helyx.TUI.Wrap.rows/2` breaks at a space. A word breaks inside only when it is wider than the row. The space at a break drops, and a continuation row starts with no space. Spaces alone never make a row: an indent too wide for the row is cut, and a space at the end makes no row. A line of spaces alone is one row. `Wrap.columns/1` is public, for the fill of a user row.
- Margins of 2 columns for the transcript, the composer, and the status bar: `Layout.split/4` with `horizontal_margin`, and `inner_width/1` for the scroll screen.
- User messages: a blue bar `▌` and a white-on-black tint on every row, with a fill of spaces that runs past the edge. ExRatatui cuts the fill; the width rule counts emoji sequences wider than ExRatatui draws them, so an exact fill left a gap.
- A run of information cells is one transcript item and one dim row, `· a · b`. The join is in `Helyx.TUI.Transcript.items/1`; the view model keeps one cell per event.
- The composer box: rounded corners in dark gray, no title, a blue `›` mark on its top row. The mark is a second widget, because `Textarea` has no prefix; it draws only inside a box of at least 4 by 3.

## Broke

- The test helper flattened the spans of a line; a user row is now two spans (bar and text), so `texts/2` joins the spans of each line.
- The margins changed the geometry of the TUI tests: the scrollback tests run at 24 columns (20 inside) and the resizes at 204.
- Review round 1: the bar made a row wider than a 3-column transcript, the `›` mark drew outside a small box, an indent split a word that fit, and the tint stopped short after an emoji sequence.
- Review round 2: a user row with no bar had no fill, so the tint stopped short (`語` at width 3, a Devanagari conjunct at width 80); an indent wider than the row stayed as a row of spaces.
- Review round 3: the docs stated an indent rule stricter than the code; a row with no bar still had a fill too short by 2 columns.
- Round 4: every user row now gets a fill of the whole width in a span of its own. Joined to the text, the fill let a last U+0600 join a space into one grapheme that ExRatatui cut whole.

## Decisions

- Colors are palette colors. White on black for the tint, because it reads in light and dark themes; dark gray with white text has low contrast in some themes. The bar marks the message where black is the background color.
- The ticket says notices join "with no blank rows around them", and the mock-up has blank rows around the run. The run has no row inside it and one around it, as every item.
- One empty row after each item, as before. It gives the row above a user message and the row above the composer in the follow view. A user message keeps the row under it, so two user messages in a row do not join into one tinted block.

## Open

- A glyph with VS16 such as `🏳️‍🌈` can leave a cell inside it untinted, because ExRatatui disagrees with itself on its width (ticket #90 class).
- Continuation rows of tool output lose the `"  "` indent of the first row. A prefix argument for `styled_lines/3` would fix that and the notice and information marks.
