## Decisions

- **Merge order of the TUI tickets, mine:** #484, then #486, then #485, because all three change `tui.ex`. #484 moved the footer out first and made room. #486 and #485 each moved their logic into a module that owns it (`Quit`, `Selection`) behind one clause. `tui.ex` is now at the limit of 400 lines.
- **#484 branch name, the owner:** keep the `/bin/sh` runner that kills git when the port closes. A hand-written `HEAD` reader drew repeat findings in rounds 1 to 3, so the mechanism moved to `git branch --show-current`. Round 4 then found that a hung git outlived the TUI, so the kill moved into sh. A plain `System.cmd` with no kill would be about 60 lines shorter. The owner kept the reviewed version.
- **#484 rebase, mine:** a conflict in `docs/features/coding-agent.md` with #487. I resolved it by hand: the #484 text, plus the #487 Markdown paragraph. No code file overlapped, so no reduced round.
- **#480 and #483, mine:** the reduced last rounds (#480 r3, #483 r4) were the orchestrator's choice after the round limit.
- **#486 rounds, the worker:** after the rebase the worker counted a new reduced cycle (two rounds), not rounds 3 and 4 of the first loop. The last round found no defect.
