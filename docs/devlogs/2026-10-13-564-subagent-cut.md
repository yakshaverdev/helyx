# 2026-10-13: #564 A stopped sub-agent makes the next cost unknown

## Done

- Two probes on `claude` 2.1.296 (haiku): an interrupt 0.5 s and 3 s after a foreground `Agent` call. The program gives the open `Agent` call an `is_error` tool result before the `result` with `aborted_tools`. So the ticket rule "no tool result" never fires as written; the code treats an `is_error` result as open too. Facts in `docs/research/claude-code-stream-json.md`, "An interrupt during a foreground sub-agent".
- `Meter` keeps the ids of the open `Agent` calls since the last `result`. An `aborted_tools` with one open sets the flag, so the next `done` has `cost: nil`.
- `Meter.line/2` reads every main-loop `assistant` and `user` line, also the lines of a program turn before the start of a Helyx turn's line (Codex, round 1).
- `claude_code.ex` stays at 555 lines, under its 556 in `.credo.exs`.

## Found

- In both probes the sub-agent calls that had ended were in `total_cost_usd`, so the flag was set where the cost was complete. Only the #557 runs show a cut sub-agent call.
- The `usage` of a `result` held only the main loop's call, so the token sums do not hold a sub-agent's tokens.
