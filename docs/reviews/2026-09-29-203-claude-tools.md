# Review: Helyx tools inside Claude Code, the shared tool path (#203)

Date: 2026-09-29. Base: `0e6a66e`, the branch base during the review. The commit was then rebased onto `1412530` (the #224 merge); the only conflict was in the feature doc, where both "Built in" sections stay. Invariant: each Helyx tool request of a connected turn runs at most once, one at a time per turn with at most 16 waiting, and gets exactly one answer written to the program: its tool result while its pair `{turn_id, call_id}` is open, else the error `aborted` at the terminal, at the interrupt before the provider sees it, or at the next turn. A late or withdrawn result is never written for any call, a call id is used once per turn, and the hands run no Helyx tool of a turn after that turn's cleanup. Entry points: the harness loop action `{:event, turn_id, {:tool_request, ...}}` of any connected provider, the Claude Code SDK MCP server `helyx` over `control_request` `mcp_message` (`initialize`, `tools/list`, `tools/call` with `_meta["claudecode/toolUseId"]`, `notifications/cancelled`), `control_cancel_request`, the `{:cancel_tool, ...}` action, and the `{:tool_result, ...}` request of the session. Accepted holes: a sub-agent `tools/call` is not in the transcript (#224); a `tools/call` outside a Helyx turn gets an `isError` answer; the `control_cancel_request` shape, the `isError: false` result, and the -32601 error are source only.

## Simplify

- Reuse: `run_harness_tool/2` copied `run_tool/2`. Fixed: `run_tool/2` calls it, then emits `tool_execution_start`.
- Reuse and simplification: the MCP tool result map was built twice, each MCP answer repeated `jsonrpc` and `{[], state}`, and the two cancel paths repeated the lookup. Fixed: `tool_answer/5`, `mcp_answer/3` adds `jsonrpc` and returns `{[], state}`, `cancel_call/2` takes a match function.
- Skipped: the O(n) lookups over at most 17 calls, and building `tools/list` once per `initialize` (efficiency; the counts are bounded).
- Skipped: one map of open harness `from` refs by kind instead of `results` in the steer wait, and one tool queue for local and connected turns (altitude). Both are larger changes of the session; the two stores are documented in `Helyx.Session.Turn`.
- Skipped: the test helper for the two withdraw tests of the Claude provider.
