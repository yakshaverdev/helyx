# 2026-10-18: review of skills (#471)

## The first `/ship` run (with `yaml_elixir`), superseded

Two rounds on the version that parsed the frontmatter with `yaml_elixir`. Round 1 found 3 reproduced defects (aliases that expand past the memory of the node, a `!!binary` description that is not UTF-8, deep nesting in quadratic time), fixed with a parse process with a heap bound and a deadline. Round 2 found 2 more defects in that process (12: the copy of the result lost the sharing of aliases; 13: the process outlived a killed caller), and precommit found 2 more (16: the deadline dropped a valid skill on a loaded host; 17: `fields/2` over the Credo complexity limit). The orchestrator removed the premise: no YAML library, a reader of only `name` and `description` in the caller, linear in the bytes. Findings 12, 13, 16, and 17 went away with the process.
