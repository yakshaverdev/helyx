Ticket #878. Base `9c25ff2a` (merge base with `origin/master`). The ticket has no triage comment; ADR 0011 holds the owner's decisions.

## Accepted holes

- The mark of a Helyx tool request whose call never becomes open (never streamed, or already answered) stays until the end of the turn, with at most 8 result blocks. The requests of a turn have no count bound, so the marks have none (round 5, finding 3).
- A block that a Task shows before its call streams is refused (`{:error, :not_running}`).
- `:ui_block` events have no rate cap; the credits and the transport bound the bytes queued to a subscriber (ADR 0011, "Bounds").
- The end of a background run drops the blocks of its return: it is a user message, not a tool result.
- The local run of `plugins/bundled/test/helyx/tui_test.exs` fails on this machine because of the skills installed in the home folder (a "skills were left out" notice in the transcript); precommit runs on the precommit host.
