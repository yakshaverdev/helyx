# Review: JSON.decode can raise at the disk, harness, and OpenAI boundaries (#786)

Scope: the working tree against the branch base `5216403d`. Files: `lib/helyx/session/file/reader.ex`, `plugins/bundled/lib/helyx/harness_io.ex`, `plugins/bundled/lib/helyx/provider/openai/events.ex`, `plugins/bundled/lib/helyx/model_info/catalog.ex`, their tests, and four feature docs (`coding-agent.md`, `session-list.md`, `long-lived-harness.md`, `usage-and-limits.md`).

Invariant: no JSON decode of outside data raises on an integer over the largest integer of the BEAM. Each boundary gives its existing answer of bad JSON: the session file resume skips the line; a harness stdout line is skipped; OpenAI tool call arguments go on as raw text, and Core fails the turn; a models.dev cache file gives the snapshot, and a refresh body keeps the last good copy, with a normal end of the refresh process.

## Measurement

- Elixir 1.19.5, OTP 28. 1,262,593 nines and the same with `-` raise `SystemLimitError`; 1,262,592 nines decode; each decode takes about 205 ms. `1e400` returns `{:error, {:unexpected_sequence, ...}}`. The spec and failure-path reviewers probed floats (`1e400`, `1e-400`, large exponents, a large integer with a fraction or an exponent), deep nesting, bad surrogates, and bad UTF-8: each returns an error or a value. Only a pure integer raises.
- Each new test fails on the base and passes with the change (author for all; the spec reviewer ran them against the base modules). On the base: the resume gives `{:invalid_file, "a system limit has been reached"}`; the harness and the OpenAI stream raise `SystemLimitError` in the caller; the cache read raises in the lookup; the refresh process exits with `SystemLimitError` and logs a crash report.

## Simplify

One agent. Applied: the harness test puts the line in the fake's script (`turn(bin, 1, 1, [line | reply("ok")])`), with no temp file; the session file test binds the digits once. Rejected: a shared decode helper (see "Round 1", standards); a module attribute for the digits (1.2 MB in the BEAM file).

## Accepted holes

- A skipped harness line can leave a turn waiting until an abort (for example a skipped `result` line). This is the existing rule for every stdout line that is not a JSON object; not probed.
- The decode of an integer near the limit takes about 205 ms of CPU, at each boundary.
