# Review: #513 Queued text goes back to the client, and each follow-up gets its own turn

Invariant: `Queue.abort/1` is the only code that empties the steer and follow-up queues. Every abort (`TurnLoop.abort/2` with no turn, `Wait.abort/2` in a wait, `Wait.finish/2` of a turn) and every failed turn (`Wait.finish/2` with an error, from any fail path) gives each queued text back exactly once in one `queue_dropped` event, steers first and each queue in its order (a steer that the provider rejected joins the end of the steers), after the steer notices and before `turn_end`, with a nil turn id only in a wait. `Queue.provider_down/1` settles only the steer ledger and keeps both queues, so a turn that prepares and connects again sends its queued steers. At a normal turn end `Queue.drain/1` starts one turn with every queued steer together, or else with only the first follow-up, and each later turn end starts the next until the queue is empty. The TUI (`Helyx.TUI.Composer.apply/2`, from `handle_info`) puts the texts, cleaned by the paste rule, before the draft and a recalled prompt that shows, edited or not, one per line, and keeps the paste markers of both.

Accepted holes: the event names no client, so every subscriber's composer gets the texts; a client that subscribes after the event never sees them; each text is unbounded human input (#29), as at send, and one event holds at most 32 steers and 32 follow-ups. The ticket's bounds line ("at most the queue limit of entries (32), each already bounded at input") does not match the code: the steers and the follow-ups have a limit of 32 each, and `Helyx.Session.send_text/3` checks only UTF-8. The docs state the code's bounds. A dropped text that starts with `/model` from another client makes Enter read the composer as a model switch; the bundled TUI never queues one. A recalled prompt that shows comes back even when the user did not edit it: the composer keeps no edit flag, and the user can delete the line.

Decision source: `docs/reviews/2026-10-12-domain-review.md`, section 12, row C2, A7, Q4. Scope addition from the orchestrator: the `Helyx.Session.abort/1` @doc, which called an abort with no turn a no-op, also in a wait.
