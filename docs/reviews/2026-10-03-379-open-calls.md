## Invariant

The open tool calls come only from the transcript: the calls of the last assistant message that the tool results right after it do not answer (`Transcript.open_calls/1`). Entry points: the `:tool_result` stream event, `message_end` through `Messages.close_assistant/3`, a taken steer, the normal turn end, an abort, a failed turn, and the snapshot `running` list. `Messages.abort_open_calls/1` is the one writer of the `aborted` results. The property rests on the rule "no message goes between a call and its result": every writer of a non-result message (`append_user`, `close_assistant`, `take_steer`, the turn ends) runs `abort_open_calls` first, and `Steering.append_steers/1` runs only in `:preparing`, before the first assistant message of the turn.

Accepted: a call id reused across assistant messages is no longer tracked; no real provider reuses an id (#369). Documented exception: the TUI view model keeps its own whole-history pairing, which gives the same result on a transcript the session writes.
