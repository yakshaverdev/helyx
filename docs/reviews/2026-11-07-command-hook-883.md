## Round 2 (reduced: spec and failure path)

There is no snapshot of the state before the round-1 fixes (`git stash create` refused the intent-to-add files), so both agents read the whole diff against `d3840c0c` with the fixed areas named. The first run of this round died at the usage limit of the model account before any agent reported; this is its rerun.

Invariants checked: (1) the relay is the command's reaper and ends before it only by a KILL; (2) a dropped rest of standard output fails a hook only when the kept head starts an object or is only white space; (3) a bad config entry fails only its point. The round-1 reproductions pass (65 of 65 tests). The failure-path agent confirmed (1) for a command that had closed its streams, one writing in a loop while the port closed, and one blocked on stdin; the spec agent confirmed every bounds row at the limit, one over, and multibyte, also where the text reaches the model (a 262,144-byte stderr reason reached the model as 65,536 valid bytes) and the failure text (4,000 bytes, valid at a split `é`).
