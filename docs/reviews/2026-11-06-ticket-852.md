# Review: #852, Markdown recall order by write numbers

Base: `6a5612b4` (merge base with `origin/master`). Diff: `git diff 6a5612b4`.

Invariant: `Helyx.Memory.Markdown.sync/2` stores each message once, as one file with two hard links: the id name `log/<sha>.md` and a time name `log/time/<bucket>/<seq>-<sha>.md`, linked first. `recall/2` orders the log by those names with no stat per log file, so a recall over 100,000 log files reads a new message within the default `recall_ms`.

## Round 1 (full)
