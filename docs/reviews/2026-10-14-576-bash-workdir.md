# Review: #576 A workdir argument for bash

Invariant: the bash tool runs its command in the folder that the optional `workdir` argument names, resolved with `Path.absname/2` against the session folder, or in the session folder when `workdir` is missing or `null`. A `workdir` that is not a UTF-8 string of at most 4,096 bytes with no NUL byte gives an error result, and nothing runs. A folder that the watchdog cannot enter fails the start: an error result, and nothing runs. Entry point: `Helyx.Tool.Bash.run/2`, reached through the hands and through the harness providers by the shared tool spec.

Accepted: no limit to the session folder (approval, #503, can add one). A relative path keeps `..` and `~` as given, as the ticket decides ("A relative path is resolved against the session folder. An absolute path is used as it is."); the read, write, and edit tools expand their paths with `Path.expand/2`, so `~/x` differs between them.
