# Review: #576 A workdir argument for bash

Invariant: the bash tool runs its command in the folder that the optional `workdir` argument names, expanded with `Path.expand/2` against the session folder (round 2; round 1 used `Path.absname/2`), or in the session folder when `workdir` is missing, `null`, or `""`. A `workdir` that is not a UTF-8 string of at most 4,096 bytes with no NUL byte gives an error result, and nothing runs. A folder that the watchdog cannot enter fails the start: an error result, and nothing runs. Entry point: `Helyx.Tool.Bash.run/2`, reached through the hands and through the harness providers by the shared tool spec.

Accepted: no limit to the session folder (approval, #503, can add one).

Round 1 resolved the path with `Path.absname/2`, which kept `~` and `..` as given, and named the difference to the file tools as an open choice. Owner decision of 2026-10-14: expand with `Path.expand/2`, as the read, write, and edit tools do; `""` stays the session folder. Round 2 reviews that change.
