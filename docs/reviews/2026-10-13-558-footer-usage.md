# Review: #558 The usage values in the footer

Invariant: row 2 of the TUI footer shows the session totals of every `Helyx.Usage` that is not nil (the token sums, the cache share, and the cost as `$1.23`, `≥$1.23`, `$?`, or no field, with `list` only after a sum) and the context % of the last usage when the model of its message is the current model. `Helyx.TUI.SessionUsage.add/2` folds them in `ViewModel.add_message/2`, so the live events and a snapshot after a resume give the same values. `Helyx.TUI.Footer` writes each value in its capped form (6, 10, and 5 columns), and the render cuts the row at the width.

Accepted: the usage of a turn in a provider process that ends before its next `done` is in no total (known ceiling of the feature doc). The Codex and OpenCode costs and the OpenCode window wait for #559, so their tests show `$?` and, for OpenCode, no %. No OpenCode usage chunk is recorded (`docs/research/opencode-usage.md`): the OpenCode tests use a chunk of the shape that the feature doc gives.
