# Review: #480 fuzzy edit match

Invariant: `Helyx.Tool.Edit.run/2` (public, a boundary for all arguments) rejects `old_text` or `new_text` that is not valid UTF-8, sets a leading file BOM aside and writes it back, tries the exact match first, and only with no exact match matches a per-cluster normalized form (NFKC, quotes, dashes, CRLF as LF, trailing spaces and tabs dropped) that must be unique; the match maps back to the smallest original range, and only that range changes. Accepted holes are in `docs/features/fuzzy-edit.md`: no new size limit (the normalized copy can reach 11 times the file), seconds of work on pathological 10 MiB files, an `old_text` whose last line ends in spaces matches without them, a lone CR is text.
