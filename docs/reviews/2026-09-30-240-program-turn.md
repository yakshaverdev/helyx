# Review: #240, a Claude Code program turn as a live Helyx turn

Scope: `git diff origin/master` on `ticket/240-program-turn`. An `init` line while the Claude Code provider has no turn starts a program turn. The provider gives `:program_turn` with its own UUID. The loop checks the id, makes the turn live, and sends it on. The session opens a submitted connected turn with `turn_start` `%{origin: :program}` only with no turn, no wait, and a ready harness process, and drops it otherwise. After a `task_notification`, the next idle close answers `:busy` once.

## Simplify

- Reuse and altitude: the session clause built the turn and emitted `agent_start` and `turn_start` as `begin_turn/2` does. Fixed: both call the new `open_turn/3`.
- Simplification: split the `init` clause and the `{:turn, ...}` guard into clauses. Skipped: the `init` split repeats the capability parse, and the guard reads as one rule.
- Efficiency: no finding.
